# Speed Typing Test - CS 2600 Final Project in C
## Group Members: Tyler Carrasco, Tiffany Dinh, Brandon Doan, Kendan Phan, Angela Salcido

## Purpose
This project is based on a speed typing test. Its purpose is to allow users to measure their typing speed and accuracy. It also gives them the opportunity to practice typing various words and improve their speed/accuracy.

## How to Use
The program will display 25 random words for the user to copy. They will try to type as quickly and accurately as possible. After they are finished typing, the program will display information, such as their words per minute, accuracy percentage, and the number of correct characters they typed. The user can keep retrying, but each time they restart, new randomly generated words will appear instead.

## Features
* Users are prompted with a main menu to start the game or exit the program
* Program displays 25 random words from a text file for the user to type
* If the user types extra words/characters, their accuracy score will be lowered
* Words per minute (WPM) and accuracy calculations based on what the user types and how quick they were
* After the user is finished typing, the program will output:
  * Lengths of the generated and user strings
  * Number of extra and correct characters the user typed
  * Elapsed time
  * Words per minute
  * Accuracy percentage
* Replay menu to prompt the user if they would like to play again
* Invalid user inputs
